# Reharm Lab

A jazz-piano reharmonization and practice app. This glossary names the musical and practice concepts the code is built around.

## Practice

**Drill session**:
One sitting at a drill: a sequence of runs on one concept, moving from key to key.
_Avoid_: exercise, practice loop

**Run**:
One pass through a drill's target chords in one key. A run has one or more chords and is filed once, when its last chord is played cleanly. A Coach run is a whole move; a Voicings run is a single chord, so a ii–V–I is three runs in a row.
_Avoid_: attempt (that's one strike), session, take

**Attempt**:
One strike at one target chord, graded pass or fail, by the engine or by the player (self-check).
_Avoid_: try, strike (the strike is the gesture; the attempt is its graded record)

**Miss**:
A failed attempt within a run.

**Leap**:
A chord change within a run where a voice moved by more than a step, so the change doesn't voice-lead smoothly.
_Avoid_: jump

**Clean run**:
A run with no misses and no leaps.

**Self-check**:
Grading by the player's own verdict ("nailed it" / "missed") instead of the engine, for acoustic pianos with no MIDI. A run with any self-checked attempt counts as self-graded.

**Filing**:
Saving a finished run to the practice history, where it is graded and schedules the concept's next review.
_Avoid_: saving, recording, logging

**Key plan**:
How a drill session chooses its next key. It is either a key flow or the 12-key drill.

**Key flow**:
A key plan that moves on only after a clean run: hold the key, go up in fourths, go up in fifths, or pick a random key (transfer).
_Avoid_: key mode, circle mode

**12-key drill**:
A key plan that takes one concept through all 12 keys in one lap, starting with keys due for review, then weak, new and solid ones. Each key is marked clean or not, and the drill moves on either way.
_Avoid_: weak-keys drill, key survey

**Voice motion**:
How each voice gets from one chord to the next, said as at the piano: voices held, each moving voice with its spelled notes and interval, and the bass separately.
_Avoid_: motion line, voice-leading text
